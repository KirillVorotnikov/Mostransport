# Трамваи Москвы · GTFS Explorer

🌐 **Веб-приложение со встроенной моделью:** [https://mostransport-final.vercel.app/](https://mostransport-final.vercel.app/)  
🔗 **Отдельный пайплайн модели:** [https://github.com/KirillVorotnikov/mstrans_model](https://github.com/KirillVorotnikov/mstrans_model)

Веб-интерфейс для визуализации трамвайных маршрутов Москвы на карте. Приложение:

- запрашивает GeoJSON-функции набора [3221](https://data.mos.ru/opendata/3221) через `apidata.mos.ru`;
- фильтрует из набора только трамвайные записи;
- умеет читать локальный `moscow-tram-gtfs.zip`, если файл лежит рядом с `index.html`;
- определяет трамвайные записи и преобразует их в базовые GTFS-файлы;
- рисует трассы и остановки на Leaflet-карте;
- экспортирует `agency.txt`, `routes.txt`, `stops.txt`, `trips.txt`, `stop_times.txt`, `calendar.txt` и `shapes.txt` в ZIP.

## Запуск

Нужен локальный HTTP-сервер, потому что браузер блокирует `fetch` из `file://`.

```powershell
py -m http.server 8765
```

Откройте <http://localhost:8765>.

Также подойдёт любой статический сервер, например `npx serve .`.

## Источник и ключ API

По умолчанию используется:

```text
https://apidata.mos.ru/v1/datasets/3221/features
```

Если API отвечает `401` или `403`, вставьте ключ data.mos.ru в поле API-ключа и повторите загрузку. Ключ остаётся только в текущем браузере и не записывается в файлы проекта.

При недоступности API приложение не ломается: оно показывает демо-геометрию для интерфейсной проверки и явно сообщает об этом в статусе. Демо-данные не являются официальной выгрузкой.

Если рядом с приложением лежит `moscow-tram-gtfs.zip`, его можно открыть отдельной кнопкой. В текущем архиве `routes.txt` содержится 8 маршрутов — интерфейс показывает именно это количество, потому что не добавляет маршруты, которых нет в выгрузке.

## Загрузка через Python

Скрипт `download_tram_routes.py` использует только стандартную библиотеку Python. Он постранично запрашивает GeoJSON-набор 3221, оставляет записи с типом «трамвай» и сохраняет:

- `data/tram_routes_3221.geojson` — отфильтрованные маршруты с геометрией;
- `data/tram_routes_3221.csv` — краткая таблица маршрутов.

В PowerShell:

```powershell
cd "C:\Хакатоны\Мостранспорт"
$env:MOS_API_KEY = "ВСТАВЬТЕ_СЮДА_API_КЛЮЧ"
py .\download_tram_routes.py
```

После выполнения ключ можно удалить из текущей сессии:

```powershell
Remove-Item Env:\MOS_API_KEY
```

Полезные параметры:

```powershell
py .\download_tram_routes.py --output .\data\trams.geojson --timeout 90
py .\download_tram_routes.py --help
```

## Ограничение преобразования

Для GeoJSON набора 3221 точки геометрии используются как форма маршрута. Если в исходных данных нет расписания, времена `stop_times.txt` при экспорте GTFS генерируются с шагом 5 минут. Для транспортного планировщика этот экспорт нужно дополнить официальным расписанием.
